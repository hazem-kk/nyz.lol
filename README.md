# nyz.lol

Preview build of the nyz.lol landing page (bio link platform).

## Put it online
1. Upload these files to a new GitHub repository.
2. On vercel.com, click "Add New > Project", pick the repo, and deploy.
3. Add your domain nyz.lol in Vercel > Settings > Domains.
